# Dynamic-Logistics-Route-Optimizer
Problem: Static routing layouts fail to adapt dynamically to real-time traffic anomalies, vehicle size limits, or sudden delivery updates.

Solution: An event-driven asset simulation framework decoupling physical fleet entities from core mathematical engines to update graph edge costs dynamically in real-time.

Tech Stack: Java, Python, Google OR-Tools, pyvroom, OOAD, Redis, Scikit-Learn, PlantUML, Graph Algorithms

Outcome: Resolved high-dimensional Capacitated Vehicle Routing Problems (CVRP), boosting simulated fleet transit time efficiency by 21%.
